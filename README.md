# My Portfolio

This repository contains a lightweight personal portfolio website for Augustino Erick. It is a static site composed of index.html, style.css and script.js.

How to use

- Open index.html in a browser to view the portfolio locally.
- To publish, push to GitHub and enable GitHub Pages on the main branch (Settings → Pages → Branch: main).

What I changed

- Improved structure and accessibility of the HTML.
- Reworked styling with CSS variables and responsive navigation.
- Added small JavaScript for mobile navigation and smooth scrolling.
